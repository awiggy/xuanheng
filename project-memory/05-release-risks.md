> 读取场景：部署、GitHub、云端数据库、密钥、许可证、上线验收。

## 尚未完成的发布能力

- 当前数据只存在本机，不支持账户、跨设备或线上数据库。
- `.openai/hosting.json` 尚无正式持久化资源配置；Sites 页仍为占位。
- 正式上线需部署前端、Python 或等价确定性后端、持久化数据库、服务端模型密钥、日志与备份。
- GitHub 适合作为源码版本库和更新渠道；GitHub Pages 不能直接运行当前 Python 服务、保护密钥或保存云端历史。
- D 类验收必须在线上环境进行：错误与重试、数据不丢失、桌面/平板/手机、服务重启恢复、日志与备份。

## 隐私与安全

- Git 永远排除 `.xuanheng/`、本地数据库、API Key 和用户出生资料。
- 线上模型密钥只允许服务端环境变量保存。
- 验收日志不得记录姓名、出生日期、地点、经纬度、问题正文或 API Key。
- 对外文案保留传统文化研究/娱乐参考边界，不作医疗、法律、财务或人生决策承诺。
