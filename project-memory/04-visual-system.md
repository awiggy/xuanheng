# 玄夜星图视觉系统

> 读取场景：前端、布局、组件、响应式、视觉回归和术语统一。

## 已确定方向

- 用户已选择“玄夜星图”为唯一正式方向；不再并行推进雾白观象或单色薄荷。
- 基础语言：深墨背景、克制网格、金色主强调、灰阶次级信息。
- 字体角色：衬线用于标题与命理符号；无衬线用于正文与输入；等宽用于编号与眉题。
- 产品名“玄衡”放在统一品牌位；主页不再使用“观命见时，问事见行”。
- 正式内容和占位内容不能混用；面向用户不得出现 `PYTHON ENGINE`、`LOCAL FIRST`、`BAZI STUDY`、`交互前端原型` 等实现术语。

## 统一布局

- 四柱、塔罗、紫微和合缘共用同一页面原点、内容宽度与顶部导航坐标系。
- 桌面顶栏使用共享固定轨道；体系切换器固定在第二列并统一宽度，不能被右侧控件数量反向推移。
- 窄屏使用统一折行规则。
- 四柱旧 `.shell` 只保留内容网格职责，不得恢复外边距、白色半透明外框、独立圆角/阴影或顶层偏移。
- 主页功能卡和“从确定的出生时空开始”使用同一深墨卡片语言与留白节奏。

## 已实现统一项

- 四柱命盘、藏干/十神/纳音、神煞、五行、结构解读、大运、流年与流月已改为深墨卡片、金色选中与灰色次级信息。
- 塔罗空态、抽牌态、翻牌态和解读态共用同一工作台骨架。
- 紫微十二宫与合缘正式页使用同一设计系统。
- 问事空态和结果态共用档案、模式、输入及历史入口；历史使用左侧图标与抽屉，支持遮罩与 Esc。
- 出生档案页、编辑弹窗、三历标签、滚轮、输入、地图控件与操作区已切换到玄夜样式。
- 合缘与紫微空态的“新增出生档案”使用同一种金色描边次操作。

- 合并 API 配置、API 已接入和服务正常为一个全局状态入口。
- 提高 7—9px 小字字号和对比度。

- 固定成功、提示、错误和选中状态色语义。
- 用一套线性图标替换字符图标与混合箭头，统一尺寸、描边和基线。
- 保持编辑来源上下文：关闭弹窗后返回原命盘或档案来源。
