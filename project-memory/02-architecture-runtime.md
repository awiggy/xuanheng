# 工程架构与运行状态

> 读取场景：后端、数据库、接口、本地服务、缓存、故障排查。事实以当前代码和 Git 状态复核为准。

## 当前工程

- `index.html`：当前正式本地前端，覆盖主页、出生档案、四柱、岁运、问事、塔罗、紫微和合缘。
- `server.py`：本地 HTTP/API 服务，负责档案、地区、历法换算、四柱反查、排盘、分析、历史及各体系接口。
- `ziwei_engine.py`：紫微确定性排盘与动态层。
- `affinity_engine.py`：双档案合缘确定性证据计算。
- `.xuanheng/state.sqlite3`：本地数据与缓存；目录被 Git 排除，不能提交用户资料。
- `打开玄衡.command`：推荐本地入口，检测 4173 端口、启动服务并打开正确网址；终端需要保持运行。
- `.openai/hosting.json` 对应的 Sites 工程仍为占位，不是当前可用产品。

## 数据与身份规则

- 档案以稳定 ID 编辑，以出生信息 fingerprint 去重。
- “查看报告”只读取，不得触发保存、合并或更新时间变化。
- 编辑与删除档案时清理关联缓存。
- 分析、问事、塔罗、紫微与合缘结果按各自身份键缓存；历史重开复用原结果。
- API Key 存放于 macOS 钥匙串；公共模型配置存放于本地数据库。
- 验收日志写入 SQLite `acceptance_events` 并在终端输出 `[acceptance]`；不得记录敏感输入。

## 核心接口能力

- 八字：地区查询、三历换算、四柱反查、确定性排盘、岁运定气流月、分析、档案历史、问事历史与导出。
- 塔罗：78 张牌、6 种牌阵、正逆位、可复现抽牌、解读、历史、删除和 Markdown 导出。
- 紫微：状态、全盘、十二宫、星曜/四化、三方四正、大限/流年动态；时间不确定时拒绝唯一盘。
- 合缘：状态、双档案计算、解释、历史读取/删除与 Markdown 导出。

## 已确认口径

- 岁运流月从当年立春到次年立春按定气十二节生成，不按公历每月 1 日换月。
- 夜子时 23:00 后按次日日柱；早子时保留当天。
- 真太阳时沿用档案经度与时区。
- 紫微闰月当前默认按原月序，并必须在结果中提示；最终口径仍待决定。
- 紫微格局只返回名称与可核验依据，后端不直接断吉凶。

## 已知运行限制

- 静态打开 `index.html` 只能显示界面，不能调用 Python 服务或读取档案。
- 本地服务中断时，页面应显示“本地服务未连接”并拦截依赖后端的操作。
- macOS LaunchAgent 因桌面目录后台访问限制已撤销，不是交付方案。
- GitHub Pages 不能承载当前 Python 后端、服务端密钥或持久化数据库。
